# Audio and Haptics Foundation

Material/contact events originate from classified simulation impulses/relative speed, not renderer
collisions. Define wood, brass, ceramic/glass, fruit, felt, goal, hinge, warning, and restoration
families with cooldowns and voice caps. Fragility uses escalating visual + audio warning before
failure where recovery remains possible.

iOS/WebKit audio context may resume only from an intentional gesture, but asynchronous audio unlock
cannot delay, duplicate, consume, or alter the first physics command. The first action always has a
visual equivalent.

Support music/ambience/effects/haptics categories, mute, interruption, Bluetooth latency awareness,
background/resume, repeated transitions, and optional/rate-limited haptics. Haptics and audio are
never the only warning. Phase 1 implements diagnostics/interfaces, not final audio.
