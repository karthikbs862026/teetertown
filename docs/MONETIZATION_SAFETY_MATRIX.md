# Monetization Safety Matrix

| Placement/product                                                                | State                   | Rule                                                                                                 |
| -------------------------------------------------------------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------- |
| Cosmetic town/platform/trail/resident/celebration                                | Allowed later           | No collision, visibility, camera, objective, replay, or ranked advantage                             |
| Remove ads                                                                       | Allowed after ads exist | Does not change rewards or physics                                                                   |
| Post-success reward multiplier                                                   | Allowed later           | Only after classified success                                                                        |
| Partial hint                                                                     | Conditional             | Reveals safe-angle/hinge information; cannot change simulation                                       |
| One rewarded rewind                                                              | High-risk conditional   | Only after clear player-attributable failure; disabled for invalid/ambiguous and standardized ranked |
| Paid rewind/stability consumable                                                 | Deferred/high risk      | Requires trust research and economy audit                                                            |
| Battle pass/subscription                                                         | Deferred                | Requires eight-week capacity and recurring value                                                     |
| Extra tilt, friction, magnetism, stability, solver quality, easier break/capture | Prohibited              | Sells execution and changes causality                                                                |
| Paid rescue after invalid/ambiguous/engine failure                               | Prohibited              | Monetizes a defect                                                                                   |
| Interstitial after short/unclear failure                                         | Prohibited              | Creates manufactured-failure perception                                                              |
| Payer/device/network/config-specific physics                                     | Prohibited              | Violates determinism and ranked integrity                                                            |

Unlimited free restart is baseline. A firewall test must prove that payer, ad, consent, network,
experiment, and remote-config state cannot change command mapping, physics constants, collisions,
objectives, failure rules, hashes, or ranked eligibility.
