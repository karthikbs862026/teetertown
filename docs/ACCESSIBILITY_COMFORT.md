# Accessibility and Comfort

- One-finger use with either hand; no accelerometer requirement.
- Large touch controls outside the main drag path.
- Sensitivity/dead-zone presets and configurable release-to-neutral.
- Reduced camera motion, no live precision camera cuts, optional shake, reduced VFX, haptics off.
- Goal/danger/fragility cues use shape, pattern, motion, text/icon, and contrast—not color alone.
- Visual equivalents for information-bearing sound.
- Pause/restart outside mandatory callbacks; unlimited free retry.
- Unranked practice/slow mode may exist later if it changes timing, clearly separated from standard
  results.
- No mandatory rapid repeated swipe, precision hold, or strict timed input in the main campaign
  without an accessible alternative.

Automated contrast/layout checks supplement but do not replace phone-size visual review and player
testing with relevant motor/visual needs.
