# ADR-0009: Physics Authority and Assistance

**Status:** Accepted policy, 2026-07-26

Every entity is tagged dynamic, constrained, kinematic, assist, or decorative. Full physics is used
only when emergence adds readable decisions. Assistance requires a visible affordance, bounded
deterministic configuration, fixed-step ownership, overlay, replay/hash/version inclusion, and
threshold tests proving raw physics was less fair.

Invisible, payer-specific, device-specific, or unversioned rescue is rejected.
