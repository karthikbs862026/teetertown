# ADR-0006: Tilt Implementation

**Status:** Provisional, 2026-07-26

Gravity-vector tilt with a bounded presentation-root rotation is the default hypothesis because it
keeps support collider hierarchy stable. Fixed-gravity kinematic support rotation remains a lab
comparison because it may be more visually literal but risks moving-contact/joint noise.

Selection requires replay, contact/joint, CPU, reversal, overlay, authoring, physical-phone
predictability, and player-attribution evidence. No winner is claimed yet.
